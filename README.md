# EXIFMet - Advanced Metadata Extractor

EXIFMet — это мощный инструмент для анализа, сравнения и удаления метаданных из фотографий. Извлекает полные EXIF данные, GPS координаты, информацию о камере и временные метки. Работает быстро, локально и без интернета.

## Возможности

- **Полный парсинг EXIF** — извлечение всех метаданных из фото
- **GPS координаты** — интерактивная карта с локацией
- **Поддержка HEIC** — работает с фото с iPhone
- **Быстрый парсер** — собственная оптимизированная реализация
- **Очистка метаданных** — безопасное удаление приватной информации
- **Пакетная обработка** — работа с папками фото
- **Сравнение EXIF** — сравнение данных двух фото
- **JSON/CSV экспорт** — сохранение результатов в разные форматы

## Установка

### Быстрый старт

1. Скачайте `exifmet.exe` из релизов
2. Распакуйте архив
3. Запустите `exifmet.bat`

### Добавление в PATH (глобальное использование)

```bash
# Запустите install.bat
install.bat

# После этого используйте из любой папки
exifmet photo.jpg
```

## Использование

### Основные команды

```bash
# Анализ фото + интерактивная карта
exifmet photo.jpg

# Сравнение EXIF двух фото
exifmet --compare before.jpg after.jpg

# Поиск всех фото с GPS в папке
exifmet --find-gps ./vacation

# Пакетная обработка папки
exifmet --batch ./photos

# Удаление метаданных (безопасно)
exifmet --strip photo.jpg --safe

# Удаление метаданных из всех файлов в папке
exifmet --strip-all ./to_upload

# Справка
exifmet --help

# Версия
exifmet --version
```

## Поддерживаемые форматы

JPG, JPEG, PNG, GIF, TIFF, BMP, RAW, HEIC и другие

## Примеры использования

### Анализ фото
```bash
exifmet vacation.jpg
```
Выведет все EXIF данные и откроет интерактивную карту с GPS координатами.

### Сравнение фото
```bash
exifmet --compare original.jpg edited.jpg
```
Покажет различия в EXIF данных между двумя фото.

### Пакетная обработка
```bash
exifmet --batch ./photos --json
```
Обработает все фото в папке и сохранит результаты в JSON.

### Удаление приватной информации
```bash
exifmet --strip-all ./before_upload
```
Удалит все метаданные из фото перед загрузкой в интернет.
